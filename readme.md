🚀 Dashboard COVID-19 Brasil
Uma visualização clara e interativa sobre a evolução da COVID-19 no Brasil

Desenvolvido com Python, Streamlit, Pandas e Plotly.

🎯 Sobre o Projeto

Este projeto é um dashboard interativo que consome dados oficiais do Brasil.io para apresentar, de forma simples e visual, a evolução de casos confirmados e óbitos da COVID-19 em todos os estados brasileiros.

A aplicação é leve, intuitiva, responsiva e atualiza automaticamente os dados mais recentes disponíveis no dataset.

🖥️ Demonstração da Aplicação

🔹 Exibe métricas nacionais (casos totais, óbitos totais e número de estados)
🔹 Permite selecionar qualquer estado para visualizar sua evolução
🔹 Mostra gráficos interativos usando Plotly
🔹 Layout limpo e profissional com Streamlit

📊 Funcionalidades Principais

✨ Métricas automáticas do dia mais recente
✨ Filtro por estado
✨ Gráficos de evolução de casos e óbitos
✨ Leitura direta do dataset em .csv.gz
✨ Código organizado e fácil de expandir
